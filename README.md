# Performance_Metrics_BI

The Data Analytics Performance Metrics Dashboard is an interactive Power BI report designed to visualize and evaluate employee performance across multiple platforms and criteria. It provides a centralized view of key performance indicators (KPIs) such as GitHub activity, Jira task management, attendance consistency, and Confluence collaboration scores.

Key Features

Employee Selection Panel: Allows users to choose an employee from a list (e.g., Josh Fire, Adams Daniel, Adamma Eleweke, etc.) to view personalized performance metrics.

Quarter/Month Filter: Enables filtering of data by time period (Q1–Q4) for comparative analysis.

Performance Cards: Displays individual scores for each metric:

GitHub Score
Jira Score
Attendance
Confluence Score

Navigation Tabs: Provides access to detailed pages for each metric category — Overview, Confluence, Jira, GitHub, Attendance, and Processes.
Each metric is presented in a visually distinct card format with clear numeric scores and color-coded backgrounds for easy interpretation. The design emphasizes clarity and accessibility, ensuring that users can quickly assess performance levels.

Benefits

Real-Time Insights: Immediate visibility into employee performance.
Centralized Data: Combines multiple data sources into one unified dashboard.
Customizable Views: Filters and selections allow tailored analysis.
Actionable Insights: Facilitates proactive management and continuous improvement.
